## 3. Thresholds болон SLO Шинжилгээ
- **Тавьсан SLO Шалгуур:**
  - `http_req_duration`: p(95) < 500ms
  - `http_req_failed`: rate < 1% (0.01)
- **Үр дүнгийн дүгнэлт:**
  - **Error Rate:** 0.00% буюу симуляцийн турш бүх хүсэлт амжилттай (HTTP 200) буцаж байсан тул SLO шалгуурыг хангасан (`PASSED`).
  - **Latency (p95):** Хэрэглэгчийн тоо 20 болон 30 хүртэл өсөх үед p(95) хариу үйлдэх хугацаа 500ms-ээс давж (~765ms хүртэл) өссөн тул SLO шалгуур хангатгүй буюу `FAILED` (Threshold crossed) гарсан.

## 4. Дүгнэлт ба Сайжруулах зөвлөмж
1. `test.k6.io` веб сайт нь ачаалал нэмэгдэхэд алдаа буцаахгүй байгаа ч хариу өгөх хугацаа (Response Time) нь 500ms-ээс хэтэрч саатал үүсч байна.
2. Цаашид серверийн талд кэш бааз (Redis), CDN эсвэл хариу өгөх процессыг оновчлох (Database Indexing / Code optimization) шаардлагатай.
